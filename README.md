# Agnes Sys1 1.0 Decision Model

The [technical report](PAPER.pdf) describes Agnes Sys1 1.0, a Qwen3.5-9B-based decision model for classification, tool selection, request routing, and ordinal scoring. It covers block-bidirectional attention, direct extraction of candidate-option probabilities, a proposed test-time training (TTT) procedure, and a team-supplied capability table.

## Reported result and scope

The supplied evaluation table gives Agnes Sys1 1.0 an **AA Composite Index of 71.2**. The report says these figures follow prior internal estimates and were **not independently re-evaluated** for this publication. The table's “Rank 1/2/3” labels are labels from the supplied image, not current rankings. The TTT section describes an adaptation method and evaluation plan; it does **not** report measured TTT gains.

For exact wording, equations, and the source table, consult the [PDF](PAPER.pdf).
